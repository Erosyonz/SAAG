# SA-AG

**SA-AG** is a web app for recording, sharing and following hiking and walking trails. Users record a route with their phone's GPS, add waypoints with photos, and see every trail on a satellite map. Other users can open a trail, view its creator's profile, and follow the route step by step.

Built with Django, Leaflet and Tailwind CSS in a black, white and green theme.

## Features

- **Trail map**: satellite map (with an OpenStreetMap switch) that shows every saved trail as a pin with a route line.
- **Route recording**: record a walk with GPS. Points are saved as you move (as little as 1 meter), with no length limit. The final position is saved when you press Finish.
- **Waypoints**: add named spots with a description and a JPG or PNG photo while recording.
- **Trail cards and search**: trail cards on the home page come from the database. Trails from every user are shared with everyone.
- **Trail popup**: shows distance, time, climb and difficulty (Easy, Moderate or Challenging), with a link to the creator's profile.
- **Follow a route**: Google Maps-style walking mode. A walking guide leads you to the trail start, then the line gets shorter as you move along the route.
- **Profiles**: each user has a profile with photo, bio, routes created, routes finished and total km. Your own profile can be edited. Other people's profiles are read-only and hide the email, the edit button and "Trails to discover".
- **Accounts**: register, log in, log out and a settings page.

## Tech stack

| Part | Technology |
| --- | --- |
| Backend | Django 6.1, Python 3 |
| Database | PostgreSQL (Supabase) through `DATABASE_URL`, SQLite as a fallback |
| Map | Leaflet 1.9, Esri satellite tiles, OpenStreetMap tiles |
| Walking directions | OpenStreetMap foot routing (`routing.openstreetmap.de`) |
| Styling | Tailwind CSS (CDN) and custom CSS |
| Static files | WhiteNoise |
| Server | Gunicorn (see `Procfile`) |

## Database models

| Model | What it stores |
| --- | --- |
| `Account` | The user: name, username, email, profile photo URL and bio |
| `Route` | A trail: name, description, distance, climb, estimated time, creator |
| `RouteCoordinates` | GPS points of a route in order, plus the saved end coordinates |
| `RouteWaypoint` | Named spots on a route, with description and photo |
| `UserCompletedRoute` | Which user finished which route, with status and rating |

## Getting started

### 1. Clone and install

```bash
git clone https://github.com/Erosyonz/SAAG.git
cd SAAG
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
```

### 2. Create a `.env` file

Put it in the main folder, next to `manage.py`:

```
SECRET_KEY=put-a-long-random-string-here
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/postgres
```

If you leave out `DATABASE_URL`, the app uses the local `db.sqlite3` file.

### 3. Set up the database

```bash
python manage.py makemigrations
python manage.py migrate
```

### 4. Run it

```bash
python manage.py runserver
```

Open http://127.0.0.1:8000/ and log in or register.

> GPS in the browser works on `localhost` and on HTTPS sites. For real walking tests, use your phone with the deployed site.

## Deployment

1. Set `SECRET_KEY`, `DEBUG=False`, `ALLOWED_HOSTS` and `DATABASE_URL` in your host's environment settings.
2. Run these on every deploy:

```bash
python manage.py collectstatic --noinput
python manage.py migrate
```

3. The `Procfile` starts the app with Gunicorn.

WhiteNoise serves the files in `staticfiles/`. If you skip `collectstatic`, the live site keeps running old CSS and JavaScript.

## Troubleshooting

- **Changes to CSS or JS do not show up**: run `collectstatic`, then hard-refresh the page (Ctrl+Shift+R).
- **A route has no line on the map**: a route needs at least two saved points. Check `/home/api/routes/map/` and look at that route's `coordinates` list.
- **"no column named EndLatitude"**: your migrations are out of date. Run `makemigrations` and `migrate`.
- **No GPS points saved while recording**: GPS readings weaker than 100 m accuracy are skipped. Test outdoors on a phone.

## Course project

SA-AG is a school project. It uses Django ORM queries that produce an SQL JOIN (`select_related` on completed routes and their creators) and an SQL subquery (trails you have not finished yet).
